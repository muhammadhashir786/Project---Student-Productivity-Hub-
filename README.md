# Student Productivity Hub 🚀

A clean, minimalist, and responsive web application designed for students to manage their assignments, deadlines, priorities, and daily study progress in one centralized place. Built as a hackathon project to stay organized and reduce last-minute stress.

---

## 🌟 About the Project
Students often juggle multiple assignments, projects, and exams across various notebooks or phone notes, leading to missed deadlines and panic. **Student Productivity Hub** solves this problem by providing a distraction-free, focused workspace with instant tracking, persistent local storage, and a calm scholarly aesthetic.

---

## ✨ Key Features
- **Task Creation & Management:** Add tasks with a Title, Description/Notes, Due Date, and Priority levels (High, Medium, Low).
- **Priority Badges:** Visual color-coded indicators to quickly identify task urgency.
- **Persistent Storage (LocalStorage):** Data is safely stored in the browser's local storage so it won't disappear on refresh.
- **Interactive Dashboard Counters:** Real-time tracking of Total Tasks, Completed Tasks, and Pending Tasks.
- **Real-Time Task Search:** Instantly filter tasks by typing titles into the search bar.
- **Status Filters:** Easily toggle between **All**, **Pending**, and **Completed** tasks.
- **Task Edit & Update:** Edit existing task details seamlessly without deleting them.
- **Golden Scholar Theme:** A custom warm ivory/champagne background with rich golden-amber accents designed for a calm academic vibe.
- **Fully Responsive:** Optimized layout that looks great on mobile phones, tablets, and desktop screens.

---

## 🛠️ Tech Stack
- **HTML5** (Semantic structure)
- **CSS3** (Custom properties, Flexbox, Responsive media queries)
- **Vanilla JavaScript (ES6)** (DOM manipulation, LocalStorage, Array methods, Event handling)

---

## 🚀 How to Run Locally
1. Clone or download this repository to your local machine.
2. Ensure all three files (`index.html`, `style.css`, and `script.js`) are in the same folder.
3. Open `index.html` in any modern web browser or use Live Server in VS Code.

---

## 🌐 Deployment (Netlify)
This project is static and can be deployed instantly using Netlify:
1. Push your repository to GitHub.
2. Log in to Netlify and click **"New site from Git"**.
3. Select your GitHub repository and click **Deploy**.
